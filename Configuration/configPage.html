Explicit Tagger

Manages Jellyfin explicit tags and title marks. Works on its own or alongside Peanut Butter & Jelly (uses Deezer provider IDs when present).

Sources

Where to read explicit yes/no. Unknown values are left alone.

Tags

When a source says the track is explicit. Never tags albums.
Comma-separated, e.g. Explicit, NSFW
